### 1. 🌐 [Human Platform — Enterprise AI Collaboration Monorepo](https://github.com/sangamesh5588/human-platform)
> **Stack:** React Native (iOS & Android) • Turborepo • pnpm • NestJS • Prisma ORM • PostgreSQL • Docker
* Enterprise monorepo coordinating cross-platform mobile apps, portal web apps, and backend microservices.
* **Mobile Engine:** React Native client with Reanimated 3, Gesture Handler, and Native Google Sign-In.
* **Microservices:** NestJS microservice with Razorpay payments, DigiLocker identity verification, and Prisma database migrations.

### 3. 🎙️ [Nidhi Flow — Personal AI Voice Dictation Desktop Engine](https://github.com/sangamesh5588/nidhi-flow)
> **Stack:** Python 3.10+ • Groq Whisper Large v3 • OpenRouter LLMs • PyInstaller • Inno Setup • Next.js
* **Sub-Second Voice Typing:** Global push-to-talk hotkey hook (`pynput`), real-time mic streaming (`sounddevice`), and automated typing at active cursor.
* **Multi-LLM Context Cleanup:** Integrates Gemini Flash & DeepSeek to strip filler words and format punctuation in real-time.
* **Production Packaging:** Complete Windows installer (`installer.iss`) with bundled Next.js web portal and licensing.
