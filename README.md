### 🏆 Featured Production Projects

#### 1. 🅿️ [ParkDady — Smart Parking Platform](https://github.com/sangamesh5588/parkdady_user)
> **Stack:** Flutter (Dart) • Riverpod • Supabase • Google Maps SDK • Razorpay • QR Code Scanner
* Production-grade mobile parking reservation system with live GPS navigation, real-time slot occupancy tracking, and voice-assisted search.
* Integrated dynamic Razorpay checkout workflows and instant QR code ticket scanning for barrier entry/exit.
* **Companion Repos:** [park-dady-host](https://github.com/sangamesh5588/park-dady-host-) (Host spot management) & [parkconnect](https://github.com/sangamesh5588/parkconnect) (Web onboarding).

#### 2. 🎉 [SyloNow — On-Demand Services & Event Tech](https://github.com/sangamesh5588/sylonow_web_app)
> **Stack:** React • Vite • Supabase • Edge Functions • MSG91 SMS Gateway • TypeScript
* Multi-faceted platform managing event bookings, on-demand decor coordination, and real-time vendor dispatch.
* Automated client SMS notification workflows via MSG91 and Supabase database triggers with strict Row Level Security (RLS).
* **Companion Repos:** [sylono-decor-link](https://github.com/sangamesh5588/sylono-decor-link) & [sylonow-on-demand](https://github.com/sangamesh5588/sylonow-on-demand).

#### 3. 💍 [Interactive Celebration & Invitation Engine](https://github.com/sangamesh5588/wedding-invitation-card-)
> **Stack:** React 19 • Framer Motion • Vite 6 • Express • Supabase • Nodemailer
* High-performance interactive celebration experience featuring custom animations, music player integration, and live guest RSVP mailer pipelines.
* Engineered with React 19 concurrent features and responsive cross-device layout design.

#### 4. 💼 [SalesTeam — Enterprise CRM & Lead Pipeline](https://github.com/sangamesh5588/salesteam)
> **Stack:** Next.js • Supabase • Tailwind CSS • PostgreSQL
* High-velocity internal CRM built for sales pipelines, automated deal tracking, and team productivity metrics.

#### 5. 🛍️ [The Bride Label & Boutique E-Commerce](https://github.com/sangamesh5588/thebridelable)
